songleaf.ultimate_guitar¶

Ultimate Guitar: community chord charts the reader opened themselves (songleaf#28).

A community “Chords” or “Tabs” page on ultimate-guitar.com carries its chart in the page’s store (.js-store’s data-content, or window.UGAPP.store): page.data.tab_view.wiki_tab.content, in [ch]/[tab] markup, with the tab’s song_name, artist_name, tonality_name and the view’s capo.

“Official” and “Pro” pages are refused: their content lives in UG’s own player, behind its subscription, and songleaf does not circumvent content protection (terms of service, section 6.2). refusal() says why, in words a reader understands; the bookmarklet (data/web/bookmarklet.js) applies the same rule in the browser, and songleaf.importers.import_song() applies it to every import that names a UG URL.

Three routes, in the order songleaf prefers them (the terms are in misc/docs/sources.md):

  1. paste the chart into the page (no contact with UG at all);

  2. the bookmarklet, run in the reader’s own browser on a page they opened: it reads the chart from that page and hands it to songleaf’s import form, where the reader confirms it;

  3. UltimateGuitarURLSource, which fetches one URL per call. It is for a local command line only: off unless SONGLEAF_UG_URL=1 is set, never in songleaf.sources.default_sources(), never behind an HTTP route, and it

    never searches.

All UG-derived songs carry provenance.license = "personal".

>>> refusal("https://tabs.ultimate-guitar.com/tab/invented/song-official-123")[:22]
'This is an official or'
>>> refusal("https://tabs.ultimate-guitar.com/tab/invented/song-chords-123")
''
>>> ug_key("https://tabs.ultimate-guitar.com/tab/invented/song-chords-123")
'ug:123'

class songleaf.ultimate_guitar.UltimateGuitarURLSource(*, fetch=<function fetch_page>, enabled=None)[source]¶

Bases: object

One UG chord page, by URL: local command line only, off by default.

It never searches (search() returns nothing) and is never among songleaf.sources.default_sources(). get() fetches the one page it is given, refuses official and Pro pages, and returns the chart as a Song keyed ug:<id> (see ug_key()).

Parameters:

  • fetch (Callable[[str], str]) – url -> html; the default makes one plain HTTPS request.

  • enabled (bool | None) – Whether fetching is allowed; defaults to SONGLEAF_UG_URL=1.

get(url)[source]¶

The chart at url as a song (raises RefusedPage, or ValueError when off).
