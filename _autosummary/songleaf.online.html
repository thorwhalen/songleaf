songleaf.online¶

Web expansion: find a song on chord and lyrics sites, extract it, keep it locally.

When the local search finds nothing by title or artist (or when asked), songleaf asks a list of web sites. Each site is a strategy with one interface:

  • find(query, *, limit, fetch) -> list[Candidate]: the site’s own search;

  • extract(candidate, *, fetch) -> Song: one result, in songleaf’s own format.

expand() ranks every site’s candidates against the query, extracts the best one that passes is_usable(), and writes it to the song store (seam 2) as web:<site>:<id>, with the page URL, site and licence in its provenance. StoredWebSource (the web source among songleaf.sources.default_sources()) searches those stored songs, so the next search for the same song is local and makes no request.

The list of sites is configuration, not code. WEB_SITES is the registry, DEFAULT_WEB_SITES the default list, $SONGLEAF_WEB_SITES (comma-separated names) or sites= override it, and a new site is a new entry: a ChartPageSite (a search URL and a result-link pattern) for most chord sites, or any object with name, license, chords, find and extract. Why each site is or is not in the default list is in misc/docs/sources.md.

Every request goes through fetch (url -> text). The default is polite_fetch(): scraped.acquire on its plain urllib transport, robots.txt enforced, one request per second per host at most, and a User-Agent that says what it is (no browser disguise). It needs the online extra (pip install songleaf[online]).

Lyrics and charts are copyrighted: what this module fetches is kept in the reader’s own data directory, for personal use, and never belongs in a repository.

>>> site_names("lrclib, chordie")
['lrclib', 'chordie']
>>> web_key("lrclib", "123")
'web:lrclib:123'

class songleaf.online.StoredWebSource(store=None, *, kinds=('web', 'ug', 'paste'))[source]¶

Bases: object

The songs the reader brought in and kept in the song store: searched locally.

A source like any other (name "web", search, search_tiers, get): it reads the store’s keys of the kinds the reader brought in (found on the web, imported by URL, pasted), so a song kept by expand(), import_url() or a paste is found again with no request. Each hit’s source is its key’s own prefix. Title and artist match word by word, as the corpus does (WordIndex: the query inside the title and artist, or the title and artist inside the query, typos forgiven); lyrics hold every word.

Each kept song is read once per process (title, artist, words): a search lists the store’s keys and reads only the new ones. A file that cannot be read is logged and skipped, never fatal to a search.

Parameters:

  • store (MutableMapping | None) – The song store (default: songleaf.store.song_store(), resolved on each use, since the data root may move).

  • kinds (Sequence) – The key prefixes searched (default KEPT_SOURCES). Corpus songs cached in the store are not among them: their own source finds them.

songleaf.online.closeness(query, candidate)[source]¶

How well a candidate names the song the query asks for, 0-1, word by word.

The smaller of two shares: the query’s words found in the candidate’s title and artist, and the title’s words found in the query. Both must be high: a candidate whose title is one word of a long query (Dream for “silver morning dream river song”) scores low, and so does a query that names only part of the title. A word of four letters or more forgives a typo or an inflection (rivers/river).

>>> c = Candidate("s", "1", "Birds of a Feather", "Billie Eilish")
>>> closeness("birds of a feather billie eilish", c), closeness("birds of a feather", c)
(1.0, 1.0)
>>> closeness("silver morning dream river song", Candidate("s", "2", "Dream", "Rivers"))
0.4
Return type:

float

songleaf.online.expand(query, *, sites=None, fetch=None, store=None, max_extractions=3, **find_kwargs)[source]¶

Find query on the web sites, keep the best usable result, and return it.

Candidates are tried best first (find_online()); one already in store is returned as it is, without a request. Otherwise it is extracted, judged (is_usable()), given its provenance and stored under web:<site>:<id>. At most max_extractions are extracted; None when none is usable.

Return type:

Found | None

songleaf.online.find_online(query, *, sites=None, fetch=None, limit=20, min_closeness=0.6, chords_bonus=0.1)[source]¶

Every site’s candidates for query, best first: (score, candidate, site).

Each site is asked for limit results, in its own order, and all of them are ranked here: a site’s first result is often not the cleanest one. Equal scores go to the title and artist with fewer words, then to the sites’ order.

The score is the closeness() of the candidate, plus chords_bonus for a site that gives chords; candidates below min_closeness are dropped, ties keep the sites’ order. A site that fails (offline, robots.txt, a changed page) is logged and skipped.

Return type:

list[tuple[float, Candidate, WebSite]]

songleaf.online.import_url(url, *, sites=None, fetch=None, store=None, refresh=False)[source]¶

Read the song page at url and keep it, like a song a search found.

The site is found by site_for_url(); the song is stored under its key (web:<site>:<id>, or ug:<id> for Ultimate Guitar) with its provenance, and from then on found by local search (StoredWebSource). A page already kept is not fetched again unless refresh. fetch defaults to the site’s own (site.fetch) or polite_fetch().
