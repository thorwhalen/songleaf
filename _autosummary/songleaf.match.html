songleaf.match¶

Where a query matched: the words it shares with a field, as spans to highlight, and the lyric line.

Pure text functions, no corpus and no I/O. The search tags each hit with the field it matched (MATCH_KINDS); these say where in that field, so the page can mark the matched part without tokenizing anything itself.

Words are runs of letters and digits, compared case-insensitively; a query word marks a word of the text that it starts ("wond" marks "Wonderwall"), so a partly typed word is shown too. A fuzzy match with a typo marks nothing, which is honest: the words are not there.

>>> word_spans("Paper Boats", "paper")
[[0, 5]]
>>> lyric_snippet("G       D\nPaper boats drift down\nC\nthe silver stream", "silver stream")
{'text': 'the silver stream', 'spans': [[4, 10], [11, 17]]}

class songleaf.match.WordIndex(texts)[source]¶

Bases: object

Which of a list of texts (titles, say) hold which words, for matching a query word by word.

A text matches a query when the query is inside it (every query word is a word of the text, or starts one: "paper bo" finds Paper Boats) or the text is inside the query (every word of the text is a word of the query, two at least: "paper boats band" finds Paper Boats). In the first direction, a query word of TYPO_MIN_LENGTH letters or more also matches the words it is a typo of; in the second, the text’s words must be there as typed, or every short title would be a typo of some word of a long query. Unlike a fuzzy score over the whole string, a word is never matched by a piece of another word, so As is not a match for "oasis".

Memory: one sorted vocabulary, one array of row numbers per text word, and one word count per text, a few MB for 135K titles.

>>> titles = WordIndex(["Paper Boats", "Quiet Road", "Paper Moon", "As"])
>>> sorted(titles.matching("paper"))
[0, 2]
>>> sorted(titles.matching("paper boats by the band")), sorted(titles.matching("papr boats"))
([0], [0])
>>> sorted(WordIndex(["Scream"]).matching("silver stream"))  # one letter from "stream"
[]
>>> sorted(WordIndex(["Day", "The Day"]).matching("is gonna be the day"))  # one word is not enough
[1]
>>> sorted(titles.matching("oasis")), sorted(titles.matching("qui"))
([], [1])

songleaf.match.lyric_snippet(text, query, *, width=90)[source]¶

The line of text holding the most words of query (whole words), with their spans.

Lyrics match on whole words (as the search does), so a span here is a whole word. A line longer than width is cut around its first match, with … marking each cut. None when no line holds any of the words.

>>> lyric_snippet("la la\nno match here", "boats") is None
True
>>> long = "word " * 30 + "boats " + "word " * 30
>>> cut = lyric_snippet(long, "boats", width=30)
>>> cut["text"].startswith("…") and cut["text"].endswith("…"), len(cut["text"]) <= 32
(True, True)
>>> cut["text"][slice(*cut["spans"][0])]
'boats'
Return type:

dict | None
